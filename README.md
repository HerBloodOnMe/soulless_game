# Steam Library Checker

**Version:** 1.0  
**Author:** Soulless Projects  

## About
Steam Library Checker helps you decide what to play by randomly selecting a game from your Steam library. It uses the Steam API to fetch your library and display relevant details like playtime and achievements. This tool is designed to make choosing a game easier and more fun!

## Features
- Randomly selects a game from your Steam library.
- Displays playtime and achievements for the selected game.
- Launches the game directly if installed or prompts for installation if not.
- Saves your Steam API Key and User ID for future use.

---

## How to Use

### Step 1: Download and Extract
1. Download the `.zip` file containing the application.
2. Extract the contents to a folder of your choice.

### Step 2: Run the Application
1. Double-click the `game_finder.exe` file to start the application.

### Step 3: Enter Your Steam API Key and User ID
1. On the first run, you will be prompted to enter your Steam API Key and Steam User ID.
   - **Get your Steam API Key**: [https://steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey)
   - **Find your Steam User ID**: [https://steamid.io/lookup](https://steamid.io/lookup)
2. The application will validate your credentials and save them in the `auth/.env` file for future use.

### Step 4: Use the Application
1. Once your credentials are validated, the app will display a random game from your Steam library.
2. You can:
   - View the game's playtime and achievements.
   - Launch the game directly if installed.
   - Roll again to select another game.

## Troubleshooting
- **Invalid API Key or User ID**: Ensure your API Key and User ID are correct. Use the links above to retrieve them.
- **No Games Found**: Ensure your Steam library is public and contains games.
- **Error Messages**: If you encounter any errors, join our Discord for support.
